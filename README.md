#  Music Player using JavaScript

A responsive and interactive **Music Player Web Application** developed using **HTML, CSS, and JavaScript** as part of the **CodeAlpha Internship**.

The project provides a clean music-player interface with essential audio controls, playlist management, progress tracking, volume control, and autoplay functionality. The UI is designed to work effectively on both **desktop/laptop and mobile devices**.

---

##  Project Overview

The Music Player allows users to play and control audio directly in the browser.

It includes:

-  Play / Pause
-  Previous Song
-  Next Song
-  Five-Song Playlist
-  Playback Progress Bar
-  Current Time & Duration
-  Volume Control
-  Autoplay
-  Responsive Mobile UI
-  Responsive Desktop UI

---

##  Objectives

- Build a functional music player using JavaScript.
- Create a clean and attractive user interface.
- Implement basic audio controls.
- Display song and artist information dynamically.
- Add playlist functionality.
- Implement progress and volume controls.
- Make the application responsive across different screen sizes.
- Practice working with the HTML5 Audio API.
